# AeroMaravillas ✈
Página web sobre una aerolínea que ofrece vuelos a las 7 Maravillas del Mundo, desarrollada como proyecto grupal.

## Tecnologías
- HTML
- CSS
- JavaScript

## Cómo ver el proyecto
1. Clonar el repositorio
2. Abrir el archivo `index.html` en tu navegador web

## Instrucciones
En la página principal se puede observar la descripción de la compañía y los destinos que ofrece a sus clientes. Adicionalmente, en la sección **Viajes** se encuentra un formulario donde cada cliente debe completar el origen y destino del vuelo, la fecha y la cantidad de pasajeros que realizarán el viaje. Luego aparece el catálogo de destinos a los que se puede viajar, con una breve descripción del lugar y el precio correspondiente. Al final se muestran los datos de contacto para que el cliente pueda resolver cualquier inquietud directamente con la empresa.
